# Biblioteca Digital – Dani

## ¿Qué es este proyecto?
Este repositorio contiene el código de mi sitio web personal, creado con HTML y CSS, y publicado mediante GitHub Pages.

El objetivo no es vender humo ni promesas rápidas, sino documentar procesos reales para empezar online de forma inteligente rumbo a 2026.
